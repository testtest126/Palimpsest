HyperGo — an N-dimensional Go prototype

Real Go rules generalized to an N×N×… lattice in 3, 4, or 5 dimensions: groups and liberties over the full 2×D orthogonal neighborhood (6 neighbors in 3D, 8 in 4D, 10 in 5D), capture, suicide illegal unless it captures, simple ko. Rendered as nested grids — the same trick "5D chess" uses: a 4D board is a grid of 2D boards, a 5D board is a row of those grids. Click an intersection on any sub-board to play there. Standalone prototype, not part of the published Palimpsest piece.

Core engine (neighbor/adjacency, group/liberty/capture, ko) is written parameterized by dimension count — every function takes dims and n explicitly, so this same code drives 3D, 4D, and 5D play with no branching on dimension anywhere in the rules themselves. Only the rendering (how sub-boards nest) changes shape per dimension. Exposed as window.HyperGoEngine for direct testing.
