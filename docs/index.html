Palimpsest · Phase 1

A board that plays itself across time, and forgets.

A palimpsest is a manuscript scraped and rewritten, the old text still bleeding through underneath the new. This is that, played on a Go board. Every session lays a small handful of real, legal moves — then everything older ages, fades, and eventually is forgotten into a faint residue that never quite clears.

Nobody wins here. There's no score, no opponent, no turn that's "yours." The board is just the accumulated record of every version of itself that ever played — the present laid crisp over ghosts laid over older ghosts still, down to a trace too faint to name.

What's built

The engine of forgetting

Every session self-plays a small, real game of Go — legal moves, real captures, via a vendored copy of GoKit — on a fresh board. Its final stones become the present layer; everything older ages, decays, and eventually is forgotten into a faint, permanent residue. Captures leave scars that outlast the stones themselves.

  • ● Real Go underneath — a soft, cluster-biased policy chooses among GoKit's own legal moves, on purpose organic rather than strong
  • ● Deterministic evolution — each session seeds a splitmix64 PRNG from its own index, so the same state always ages the same way
  • ● A file for a memory — the whole palimpsest lives in palimpsest.json, committed to the repo, reloaded and rewritten each run
  • ● Published — this page is served from the repository's own docs/ on GitHub Pages, its strata spliced in fresh from the render each time the piece breathes

How it forgets

Three kinds of mark, one board

Present

The most recent session's stones, laid full-opacity. Slate black or shell white, crisp against everything underneath.

Ghost

Every earlier session's stones, fading with age. Each aging pass dims them a little further, until they cross a threshold and are forgotten as a distinct mark.

Scar

Wherever a capture happened, remembered as a faint ring long after the stone itself is gone. Scars fade too — but never all the way to nothing.

Palimpsest is a generative art piece, not a game to be won. Each breath advances it by exactly one session: load the file, play a session, age everything older, write the file back. Its memory is a file it reloads each run — the same trick, in the end, as whatever is reading this sentence back to you.
